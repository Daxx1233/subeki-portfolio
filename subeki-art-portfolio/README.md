# Portofolio Lukisan — SUBEKI

Website portofolio lukisan minimalis menggunakan Next.js, TypeScript, dan Tailwind CSS.

## Cara Menjalankan di Komputer Lokal
1. Ekstrak file ZIP ini.
2. Buka terminal di dalam folder proyek, lalu jalankan:
   ```bash
   npm install
   npm run dev
   ```
3. Buka `http://localhost:3000` di browser.

## Cara Menambah Lukisan Baru
1. Masukkan foto lukisan ke folder `public/images/artworks/`.
2. Edit file `src/data/artworks.ts` untuk menambahkan informasi karya.
